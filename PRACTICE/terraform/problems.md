# Terraform — Problems Hit

Every problem you hit during a lab, with its root cause and fix.

**This file is interview material.** In six months it is where your answers to
"tell me about a time something broke" come from — with real specifics, which is
the only version of that answer that convinces anyone.

Log the embarrassing ones especially. A problem you were stuck on for three
hours because of a typo is still a lesson about how you debug.

## Format

```markdown
## YYYY-MM-DD — `<the actual error text>`

**Symptom:** what you saw
**Root cause:** what was actually happening
**Fix:** exact commands
**Recognise it next time:** the tell that identifies this class in 3 seconds
**Seen before:** no | yes (date)
```

A problem logged three times means the concept was never learned, only worked
around. `/practice` watches for that and will change the lab type when it happens.
